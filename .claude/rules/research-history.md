# Результаты прошлых исследований (октябрь 2026, исторические)

Не прогноз: перед решениями о монетах — свежий `screener` и walk-forward `backtest` на нескольких задержках.

## Выводы

- Большой edge на неликвидных монетах ≠ прибыль: токсичный поток (Bybit уходит в сторону сделки HTX за 50–200 ms)
  съедает maker edge. Скринер ранжирует по запасу после токсичности.
- BTW, AKE и др. сильно портятся с ростом задержки; DOT и AVAX были устойчивы на 50/200/500 ms — поэтому их выбрали
  для первого paper-запуска на VPS (по устойчивости, а не по доходности).
- Отбор по максимальному P&L одного периода переобучает; нужен walk-forward, несколько latency-сценариев, затем paper.

## Paper на VPS и реплеи (27–31.10.2026)

- 99 ч live (100/20 ms, DOT 0.25, AVAX 0.2): +$28.8, 307 fills; 37% прибыли — 30 минут обвала 29.10 ~20:40 UTC.
- 5% самого волатильного времени (vol 5 мин > p95) дали 45–78% fills и большую часть net; в спокойные часы
  fills редкие (DOT ~0.24/ч), markout почти без минусов.
- Реплей 29.10 с одним edge на обе монеты: 0.15 → +$9.4 (в спокойные часы лучше: +2.5 против +2.0, на обвале
  +5.9 и 20% минусовых markout), 0.25 → +$14.4, 0.35 → +$9.9 (в спокойные часы 0 fills), 0.5 → +$5.5.
- В момент fill наша котировка была лучше стакана HTX в 78–90% случаев, в среднем на ~0.08% (спред HTX ~0.35–0.44%).
  Котировка «лучшая цена HTX + 1 tick, но не ближе edge» дала бы до +0.08–0.11% на fill (верхняя оценка, ~$9.8
  за 29.10, почти всё на обвале).
- Задержки на обвале: 100/20 → +$10.4, 200/50 → +9.4, 500/100 → +7.9, 1000/300 → +3.4.

## Динамические котировки (01.11.2026)

Архивы 14–23.10, DOT+AVAX, walk-forward (edge из 0.1–0.3 по 3 предыдущим дням), тест 17–23.10, $ за 7 дней:

| Вариант | 100/20 ms | 300/100 ms |
|---|---:|---:|
| fair (как сейчас) | 21.7 | 17.9 (12/14 дней в плюс) |
| skew 0.05 / 0.1 / 0.2 | 38.2 / **41.1** / 38.7 | 34.5 для 0.1 (14/14) |
| skew 0.1 + vol_edge 2 | 40.1 | — |
| vol_edge 2 | 20.9 | — |
| book | 20.2 | — |
| book + skew 0.1 | 30.0 | — |

- `skew` устойчиво удваивает результат: позиция разгружается, обе стороны котируются, fills ×2.5, markout ниже
  (~0.13 против ~0.18%), доля отрицательных markout выше (~9% против ~3%).
- `vol_edge` на архивах ничего не дал; `book` в спокойные дни не помогает, а с skew мешает.
- Реплей 29.10 (живые edge 0.25/0.2, 100/20): база +14.0; book +15.8; skew 0.1 +14.6; skew 0.2 +11.8;
  book+skew 0.1 **+19.0** (обвал 30 мин: +15.9 против +10.4); book+skew+vol (edge 0.13) +16.5.
- Вывод на 01.11: кандидат для paper — `skew = 0.1`; `book` имеет смысл только в волатильные периоды (идея:
  включать по режиму), `vol_edge` не нужен.
